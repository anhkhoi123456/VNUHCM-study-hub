4 JavaScript Architecture

main.js — Shared Utilities

Loaded by all 5 pages before </body>. All functions are globally scoped on window.

setActiveNav()

js — called automatically on DOMContentLoaded
function setActiveNav() {
  const currentPage = window.location.pathname.split('/').pop() || 'index.html';
  document.querySelectorAll('.nav-item[data-page]').forEach(item => {
    item.classList.toggle('active', item.dataset.page === currentPage);
  });
}

Reads the current filename from window.location.pathname and toggles .active on the matching .nav-item[data-page] element. Requires every sidebar link to carry a data-page="filename.html" attribute.

initPasswordToggles()

js — called automatically on DOMContentLoaded
function initPasswordToggles() {
  document.querySelectorAll('.eye-toggle').forEach(btn => {
    btn.addEventListener('click', () => { /* toggle input.type + icon class */ });
  });
}

Finds all .eye-toggle buttons and wires a click handler that toggles the sibling input.type between "password" and "text", and swaps the <i> icon class between fa-eye / fa-eye-slash.

js — globally callable

debounce(fn, ms)

js — used in dashboard.html for topbar search
function debounce(fn, ms = 300) → Function

Returns a debounced wrapper around fn. The inner call fires only after ms milliseconds of silence. Uses setTimeout / clearTimeout with a closure over t.

dev-banner.js — Dev Banner Logic

Loaded by all 5 pages after main.js. Wrapped in a self-invoking IIFE — no global namespace pollution.

CONFIG object

js — edit this to change any banner text or version
const CONFIG = {
  version:     'v0.1.0-pre-alpha',
  label:       '🚧 Đang phát triển',
  description: 'Nền tảng hiện đang trong giai đoạn phát triển...',
  storageKey:  'devBannerDismissed',  // sessionStorage key
};

All user-facing strings are centralised here. No HTML files need to be edited to change the version or message.

buildBanner() (private)

function buildBanner() → HTMLElement

Creates and returns the #devBanner div with all inner HTML populated from CONFIG. Sets role="status" and aria-live="polite" for accessibility.

init() (private, IIFE entry point)

function init()
  1. Reads sessionStorage.getItem(CONFIG.storageKey) — if 'true', adds .hidden to the banner (no body padding applied)
  2. Calls buildBanner() and appends to document.body
  3. Attaches click on .dev-dismiss: adds .hidden, removes has-dev-banner from body, writes 'true' to sessionStorage

Session behaviour: Dismissed state resets when the browser tab closes. On the next session the banner reappears automatically.

9 Going to Production Checklist

🚨
Complete all items before deploying to a public URL.
  • Remove the dev banner — delete <link rel="stylesheet" href="css/dev-banner.css" /> and <script src="js/dev-banner.js"></script> from all 5 pages
  • Connect a real auth backend — replace the setTimeout redirect in index.html with an actual API call
  • Implement search — replace showToast() stubs in dashboard.html and library.html with real search/filter requests
  • Implement AI endpoints — replace the rotating responses[] array in chatbot.html with calls to an LLM API
  • Implement AI Planner generation — connect the "Tạo lại lộ trình" button to a backend sprint-generation API
  • Add real document data — replace hard-coded file cards with dynamic API responses
  • Minify assets — run CSS and JS through a minifier for production builds
  • Add a favicon — add <link rel="icon"> to all pages
  • Update meta description tags on each page for SEO
  • Test on mobile — verify the 768 px and 900 px responsive breakpoints on real devices
